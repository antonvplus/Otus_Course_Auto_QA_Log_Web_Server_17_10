# Web Log Analyzer

Консольный Python-скрипт для быстрого парсинга и анализа серверных логов. 

Скрипт умеет работать в автоматическом режиме как с отдельными файлами логов, так и со всеми файлами в указанном каталоге.

## Возможности скрипта
* Подсчет **общего количества** обработанных сервером запросов.
* Статистика распределения по **HTTP-методам** (GET, POST, PUT, DELETE...).
* Топ-3 **IP-адресов**, с которых пришло наибольшее число запросов.
* Топ-3 **самых медленных запросов** (по времени выполнения `duration`) с детализацией: IP, дата/время, HTTP-метод, Referer и длительность.
* Вывод результатов в консоль в формате JSON и одновременное **сохранение отчета в `.json` файл**.

## Требования к структуре логов (Log Format)
Скрипт использует регулярное выражение, которое ожидает строго определенный порядок полей в каждой строке лога:
`IP [Дата/Время] "Метод URL HTTP-версия" Статус Байт "Referer" "User-Agent" Длительность`

*Пример валидной строки лога:*
```text
172.19.0.1 - - [02/Sep/2026:13:47:43 +0000] "GET /administration/ HTTP/1.1" 200 110199 "http://prestashop" "Mozilla/5.0" 150
```

## Установка и подготовка

1. Убедитесь, что у вас установлен Python 3:
   ```bash
   python3 --version
   ```

## Примеры использования

### 1. Анализ одного конкретного файла логов
```bash
python3 log_analyzer.py /var/log/nginx/access.log
```

### 2. Анализ всех файлов логов в директории
При указании директории **обязательно** добавляйте закрывающий слэш `/` в конце пути:
```bash
python3 log_analyzer.py /var/log/nginx/
```

## Формат выходных данных (JSON)

После завершения работы скрипт сохраняет отчет в текущую рабочую директорию. Имя файла формируется автоматически по маске: `ДД-ММ-ГГГГ-ЧЧ:ММ-analysis-[имя_файла]-file.json`.
